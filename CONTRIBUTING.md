# Contributing

Thanks for helping improve SWISSINNO Trap Card.

## Development

1. Fork the repository and create a focused branch.
2. Make changes in `dist/swissinno-card.js`.
3. Run `npm run check` before submitting a pull request.
4. Update `CHANGELOG.md` when the change affects users.

Keep pull requests small and describe how the change was tested in Home Assistant.

## Reporting bugs

Use the bug report template and include your Home Assistant version, browser, card configuration, and relevant console errors. Remove private entity names or other sensitive information before posting.
